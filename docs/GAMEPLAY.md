# 零号信标 · 玩法说明

> 电影式视觉小说 / 互动叙事 Demo。  
> 非商业、原创未来科幻故事；无任何现有作品角色或剧情。  
> 故事聚焦亲情、记忆与人工智能，不涉及政治阵营或现实映射。

---

## 1. 基本流程

1. 标题画面选择「开始接收」。
2. 观看片头，进入序章。
3. 点击画面 / 空格推进对话。
4. 在关键节点做出选择。
5. 根据选择进入「回声」或「安息」结局。
6. 结局后可返回标题、查看画廊，或从章回选择重玩。

一周目约 **25～30 分钟**。

---

## 2. 界面

### 标题画面

- **开始接收**：新游戏
- **继续信号**：读取自动存档
- **章回**：选择已解锁章节
- **回声画廊**：查看已解锁场景与结局
- **设置**：文字速度、自动等待、音量、减少动态
- **制作名单**：AI 生成与授权说明

### 游戏界面

- 左上：章节 / 标题
- 右上：AUTO、SKIP、LOG、SAVE、菜单
- 中央：角色立绘 + 场景
- 底部：说话人 / 台词 / 行数
- 选项出现时：角色变暗，对话隐藏，显示选择卡片

---

## 3. 操作

| 操作 | 功能 |
|---|---|
| 点击画面 | 推进；文字未显示完时先显示完整文本 |
| `Space` / `Enter` | 同上 |
| `A` | 自动播放开 / 关 |
| `S` | 快进开 / 关 |
| `L` | 回看记录 |
| `Esc` | 暂停 / 关闭弹窗 |
| `SAVE` | 存档 / 读档 |
| `☰` | 暂停菜单 |

手机：点击即可推进；所有按钮支持触控。

---

## 4. 自动 / 快进 / 回看

### 自动播放

- 默认开启；可在右上角 AUTO 或按 `A` 关闭
- 文字显示完成后，等待配音结束 + 设定延迟，再自动推进。
- 可在设置中调整等待时间。
- 遇到选择自动停止。

### 快进

- 快速推进已读/未读文本。
- 遇到选择自动停止。
- 会停止当前语音。

### 回看

- 打开最近 200 条对话记录。
- 只读，不回退剧情。

## 5. 选择与分支

游戏有 **3 个关键选择**：

### 序章 · 死频

> 你握着频道开关。雨声在耳机里越来越大。

- **回应她**：林澈回应林汐的回声。
- **保持静默**：先追踪信号来源。

影响后续台词与林澈的心理描写，不直接决定结局。

### 第一章 · 下潜

> 弦的 hologram 在雨里闪烁。沈岚的手已经按在封存开关上。

- **相信弦**：让她接入穿梭机主机。
- **交给档案馆**：先把核心封存，带回白塔。

影响第二章对话与角色关系。

### 第二章 · 回声

> 零号信标的接口就在你手边。

- **留下弦**：把回声写进档案阵列 → **回声**结局。
- **让林汐安息**：关闭信标，让告别发生 → **安息**结局。

---

## 6. 两个结局

### 回声

林澈把接口接进档案阵列。  
弦成为一份不会衰减的记忆，也成为新的自己；林汐的回声从此只存在于档案里。

### 安息

林澈拔掉接口，让林汐的回声终于结束。  
他带着弦离开白塔，去找一个不需要把谁写进档案的地方。

结局解锁后会记录在「回声画廊」。

---

## 7. 存档

- 自动存档：进入场景、推进台词、做出选择时写入。
- 手动存档：SAVE 面板，1～3 号档位。
- 读档：从标题「继续信号」读取自动存档，或 SAVE 面板读取手动档。
- 存档保存在浏览器 `localStorage`。
- 换浏览器 / 域名 / 清理站点数据会丢失存档。

## 9. 设置

- **文字速度**：8～45ms / 字
- **自动等待**：0～3 秒
- **音乐 / 配音 / 音效**：独立音量
- **减少动态**：关闭片头视频、打字机与强动效

设置保存在 `localStorage`。

---

## 10. 画廊与章回

### 回声画廊

- 场景在首次进入时解锁。
- 结局在达成时解锁。
- 未解锁场景显示为模糊剪影。

### 章回

- 序章默认解锁。
- 进入新章节后解锁对应章回。
- 章回选择从该章开头重新开始，已解锁结局保留。

---

## 11. 音频

- **配音**：143 句，Edge 神经 TTS 生成；弦 / 沈岚 / 林汐使用不同声线。
- **音乐**：WebAudio 实时合成，按场景切换。
- **音效**：UI、警报、扫描、心跳、电源、故障等，WebAudio 合成。
- 首次点击后音频初始化（浏览器自动播放策略）。
- 全部音频为原创合成 / 生成，无第三方采样。

详见 [AUDIO.md](AUDIO.md)。

## 13. 常见问题

**Q：为什么没有战斗？**  
A：这是视觉小说 Demo，重点验证图像、配音、故事与电影化演出，不是战棋。

**Q：配音是 AI 生成的吗？**  
A：是 Edge 神经 TTS 生成；不是 MiniMax H3。H3 负责图像/视频。详见 AUDIO.md。

**Q：音乐有版权吗？**  
A：没有第三方音乐；全部为 WebAudio 实时合成的原创配乐。

**Q：可以商用吗？**  
A：不可以。项目为非商业 Demo；代码 MIT，生成素材 CC BY-NC 4.0。

**Q：故事和角色有原型吗？**  
A：没有。故事、角色、组织、城市、事件均为原创，不含任何现有作品角色或剧情。

**Q：为什么角色立绘背景是透明的？**  
A：H3 生成绿幕立绘后做了色键抠图，用于视觉小说式角色站位。
